# بناء APK تلقائيًا عبر GitHub Actions

1. أنشئ مستودع GitHub جديدًا.
2. ارفع محتويات هذا المشروع كاملة إلى المستودع.
3. افتح تبويب **Actions**.
4. اختر **Build Android APK**.
5. اضغط **Run workflow**.
6. بعد نجاح البناء، افتح التنفيذ الناجح ثم قسم **Artifacts**.
7. نزّل `InsuranceGuide-debug-apk`.

المسار المتوقع داخل الأرشيف هو `app-debug.apk`.
