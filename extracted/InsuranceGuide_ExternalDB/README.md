# الدليل التأميني — External Database Edition

نسخة Android مستقلة عن قاعدة البيانات. لا توجد قاعدة Domw داخل APK.

## تشغيل التطبيق
1. ثبّت APK.
2. افتح التطبيق.
3. اختر «إدارة قاعدة البيانات» أو «اختيار قاعدة البيانات».
4. حدّد `Domw.zip` أو ملف SQLite متوافق من الهاتف.
5. ينتظر التطبيق حتى يتحقق من SQLite والجداول ثم يبدأ الاستخدام.

## الصيغ
- `.zip` يحتوي على SQLite: يتم فك الضغط تلقائيًا.
- `.db`
- `.sqlite`
- `.sqlite3`

## قاعدة البيانات
القائمة المطلوبة حاليًا:
`EMP`, `Pension`, `BANKS`, `BRANCHES`, `GOVS`, `POST`, `PHONE`, `LAWS`, `LAWP`.

لا يتم رفع قاعدة البيانات إلى خادم. يتم نسخها إلى مساحة التطبيق الخاصة للاستخدام المحلي، ويمكن استبدالها بقاعدة أخرى متوافقة دون إعادة بناء APK.

## البناء
يتطلب JDK 17 وAndroid SDK 35 وGradle Wrapper صالحًا. GitHub Actions يثبت SDK ويبني `app-debug.apk`.

> ملاحظة: هذا المشروع لا يحتوي على `Domw.zip` داخل `assets` عمدًا.
