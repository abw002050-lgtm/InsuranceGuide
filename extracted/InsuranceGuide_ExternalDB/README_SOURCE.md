# InsuranceGuide — Source Code V9

This archive contains the editable Android project source extracted from the V9 BuildFixed package.

Main locations:
- app/src/main/java or app/src/main/kotlin: application source code
- app/src/main/res: Android resources
- app/src/main/assets: local database and content
- app/src/main/AndroidManifest.xml: application manifest
- Gradle files: build configuration
